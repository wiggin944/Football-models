# Data attribution

This project uses **StatsBomb Open Data**, including StatsBomb 360 freeze-frame data.

Data source: **StatsBomb / Hudl Statsbomb Open Data**

Official repository:

- https://github.com/hudl/open-data

StatsBomb's Open Data publication terms request that research, analysis or insights based on the data identify StatsBomb as the data source and use the StatsBomb logo when publishing or sharing the work.

Media pack and logo guidance:

- https://statsbomb.com/media-pack/

## Repository policy

Raw StatsBomb event and 360 JSON files are **not redistributed in this repository**.

The source scripts download the required public data locally. Derived modelling artefacts may be included where useful for reproducibility, but the underlying raw data remains subject to StatsBomb's own terms.

This repository's code and analysis are independent work and are not affiliated with, endorsed by, or produced by StatsBomb or Hudl.
